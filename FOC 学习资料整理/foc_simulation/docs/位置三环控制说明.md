# 位置三环控制说明

## 1. 控制结构

完整三环控制为：

```text
位置目标 theta*
  -> 位置 P 环
  -> 目标速度 omega*
  -> 速度 PI 环
  -> 目标 q 轴电流 Iq*
  -> d/q 电流 PI 环
  -> Vd/Vq
  -> SVPWM
  -> 电机模型
```

其中：

- 位置环决定“还差多少角度”，输出速度目标。
- 速度环决定“速度差多少”，输出转矩电流目标 `Iq*`。
- 电流环决定“实际电流差多少”，输出 `Vd/Vq`。

## 3. 关键参数

```python
position_kp=16.0
position_velocity_limit_rad_s=18.0
velocity_kp=0.075
velocity_ki=0.8
```

`position_kp` 越大，位置误差会更快转换成速度目标；过大时可能造成速度环压力增加。
`position_velocity_limit_rad_s` 用来限制位置环输出，避免位置误差较大时直接给出过大的速度目标。
