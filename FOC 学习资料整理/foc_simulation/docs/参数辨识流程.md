# 参数辨识流程

## 1. 电阻 R

使用电压阶跃后的稳态电流估计：

```text
R = V / I_steady
```

脚本入口：

```bash
python3 examples/identify_rl.py --input data/rl_step.csv
```

如果 `data/rl_step.csv` 不存在，脚本会自动生成一份仿真阶跃数据。

## 2. 电感 L

RL 阶跃响应：

```text
i(t) = V/R * (1 - exp(-tR/L))
```

先估计 `R`，再通过电流上升曲线拟合时间常数：

```text
tau = L / R
L = R * tau
```

输出：

- `outputs/rl_params.json`
- `outputs/rl_identification.png`

## 3. 摩擦 Fc/B

摩擦模型：

```text
tau_friction = Fc * sign(omega) + B * omega
```

在加速度接近 0 的恒速段，用最小二乘拟合：

```text
tau = Fc * sign(omega) + B * omega
```

## 4. 惯性 J

从动态加减速段拟合：

```text
tau - tau_friction = J * alpha
```

脚本入口：

```bash
python3 examples/identify_friction_inertia.py --input data/friction_sweep.csv
```

输出：

- `outputs/friction_inertia_params.json`
- `outputs/friction_fit.png`

## 5. 接入真实硬件数据

真实硬件到位后，可以继续复用同一套脚本。只需要让 CSV 至少包含：

```text
time_s
velocity_rad_s
torque_nm
```

如果没有 `torque_nm`，也可以提供：

```text
iq_a
```

脚本会用 `torque = Kt * Iq` 估计力矩。
