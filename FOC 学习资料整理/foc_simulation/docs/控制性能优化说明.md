# 控制性能优化说明

## 1. 优化目标

本轮优化不是改变 FOC 的基本原理，而是让仿真更接近真实伺服控制器：

- smooth 模式下，原始速度命令先进入轨迹层，避免速度阶跃带来无限加速度。
- precision 模式下，不重设目标速度，直接跟踪原始命令，提高速度跟随精度。
- 电流环和速度环参数由电机参数计算初值，减少纯经验调参。
- 电流环加入 d/q 电压前馈解耦，降低高速或换向时的电流跟随压力。
- 速度反馈可以由模拟编码器角度差分得到，用来观察量化和滤波影响。

## 2. 新增代码位置

- `src/trajectory.py`：速度轨迹规划，输出 `position_ref / velocity_ref / acceleration_ref`。
- `src/tuning.py`：根据 `R/L/J/B/Kt` 计算电流环和速度环 PI 初值。
- `src/estimators.py`：模拟编码器量化、低通速度估计和简化 PLL 估计。
- `examples/run_control_optimization_compare.py`：baseline、smooth、precision 对比测试。

## 5. 当前测试结果

当前 `run_control_optimization_compare.py` 的结果：

```text
baseline command velocity RMS  = 1.52965 rad/s
precision command velocity RMS = 0.73683 rad/s
smooth target velocity RMS     = 0.43334 rad/s
baseline Iq peak               = 0.24797 A
precision Iq peak              = 1.34576 A
```

评价：

- precision 相对原始命令的速度 RMS 误差下降到 baseline 的约 48.17%。
- smooth 相对轨迹目标的速度 RMS 误差为 0.43334 rad/s，但它不适合用原始硬阶跃命令直接评价。
- precision 的 Iq 峰值约为 baseline 的 5.43 倍，说明更精确跟随速度阶跃需要更大的转矩电流。
- precision 的电压饱和比例约为 0.006%，当前仍在可控范围内。

## 6. 与参考项目的对应关系

SimpleFOC 对应关系：

- `loopFOC()`：对应本项目 `run_foc_simulation()` 中的电角度、电流反馈、d/q 电压计算。
- `move()`：对应速度目标进入速度环并输出 `Iq_target`。
- `setPhaseVoltage()`：对应 `inverse_park()` 和 `calculate_svpwm()`。

moteus 对应关系：

- 轨迹规划：对应本项目 `VelocityTrajectoryPlanner`。
- 位置/速度/力矩级联：当前先实现速度环 + 电流环，保留 `target_position_rad` 便于后续扩展位置环。
- 前馈力矩和电流 PI：对应本项目 `feedforward_current()`、电压前馈解耦和 PI 限幅。
