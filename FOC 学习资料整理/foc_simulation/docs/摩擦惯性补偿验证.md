# 摩擦惯性补偿验证

## 1. 补偿公式

前馈补偿使用：

```text
tau_ff = J_hat * alpha_ref + B_hat * omega_ref + Fc_hat * sign(omega_ref)
```

在代码里为了避免零速附近突变，实际使用平滑符号函数：

```text
Fc * tanh(omega_ref / eps)
```

然后换算成 q 轴电流前馈：

```text
Iq_ff = tau_ff / Kt
```

## 2. 验证方式

运行：

```bash
python3 examples/run_compensation_compare.py
```

脚本会分别运行：

1. 无前馈补偿。
2. 加入摩擦和惯量前馈补偿。

然后对比：

- 速度误差 RMS。
- 位置误差 RMS。
- 峰值速度误差。
- 峰值位置误差。

## 3. 输出文件

```text
data/compensation_no_ff.csv
data/compensation_with_ff.csv
outputs/compensation_compare.png
outputs/compensation_metrics.json
```

## 4. 结果判断

如果补偿有效，应看到：

1. `with_compensation.velocity_rms_rad_s` 小于 `without_compensation.velocity_rms_rad_s`。
2. 低速换向附近速度误差减小。
3. 加减速段跟踪滞后减小。

这只是离线仿真验证。真实硬件上还需要重新辨识摩擦和惯性，并且必须设置电流、速度、加速度和温度保护。
